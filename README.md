# Predictive Analytics for House Rental Prices in Saudi Arabia
This project explores a dataset of houses listed for rent scraped from **Aqar** platform. It includes the analysis and visualization of how different house features influence the rental price, and to training a machine learning model for price prediction. Please refer to the [notebook](https://github.com/y-alzahrani/saudi-house-rental-price-analysis/blob/main/notebook.ipynb) to view the results.


*Note: The plots were made using Plotly, but since GitHub does not support interactive plots they were rendered as static images.*
